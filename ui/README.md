# DNDTracker Blazor UI

Interfaccia Blazor WebAssembly per la gestione delle campagne, con un tavolo da
Game Master ispirato alle interfacce dei virtual tabletop e un bestiario
completo.

```bash
dotnet run --project ui/DNDTracker.Blazor.csproj
```

Per impostazione predefinita l'API è disponibile su `http://localhost:5169`.
L'indirizzo può essere modificato in `wwwroot/appsettings.json`.
